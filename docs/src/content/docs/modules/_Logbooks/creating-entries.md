## 4.1 Creating record from blank form

Users can create Logbook entries (logs) by clicking the Add Entry button at the top right corner of the screen,

The Logbook data entry form consists of standard and custom data entry fields configured for each instance of Logbook.

Image50

Once the form is flied out, press Save to save the record to the database, or press Cancel to Exit the form without saving the record.

## 4.2	Creating record from existing record
Users can create new records by using the existing record as the starting point. This brings up the content of the existing record into the form. The user can then edit the relevant fields and save them as new records.

Find the record to be used as the basis/template, click … and then click Copy Log

Image51

Edit the relevant fields and press Save
